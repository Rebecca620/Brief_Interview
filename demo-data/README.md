# Two-and-a-half-minute demo

All files are fictional. This is the small English demo set; the `test-kit` folder in the submission contains additional synthetic valid and invalid fixtures.

## Expected result

Import `notes.txt`, `metrics.csv` and `rollout.png`. Expect five cards: three text/decision cards, one metric and one image. The metric is 80 / 100, or 80% of target. The decision still needs an owner and a deadline. The original material remains available as evidence. Do not treat the image's department bars as additional measurements inferred by the app.

## Native app

1. Open Brief and click the document icon in the menu bar. Choose New report, then add the three files and build the draft.
2. Confirm the metric. Edit the decision, set owner to `Sam Rivera`, choose a future due date and save.
3. Edit a progress sentence directly. Wait for the saved status.
4. Edit the image card and add this description: `Fictional pilot readiness chart. The caption reports 80 devices ready against a target of 100. Department bars show IT 80, Operations 20 and Unassigned 0.`
5. Open Share and copy formatted content, or open Export and preview PNG. Cancel native share/save dialogs when demonstrating cancellation. Do not send an actual message.

## Browser fallback

In the browser workspace, choose New report, attach the same three files and choose Create my update. Continue with the same editing and sharing steps. This demonstrates the shared web workflow; it does not demonstrate native Finder drag/drop or OS dialogs.
