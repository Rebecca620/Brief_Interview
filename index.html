    File formats & import options

    CSV columns: title, value, target. Values must be non-negative and targets greater than zero. Download an example CSV.

    JSON/JSONL: choose numeric data or evaluation results, map fields, then select findings. Arrays, wrapped record collections, and Eval Studio compress candidates are supported. HTML text and flat tables, TXT, Markdown, PNG, JPG, and WebP are also supported. Interactive HTML scripts are not executed; link to a hosted chart or import a PNG preview. PDF selectable text and Word .docx body text are supported with a review step. Scanned PDFs need OCR; embedded document images and original layout are not imported. Older .doc files must be saved as .docx.

    Use explicit “Progress:”, “Needs a decision:”, or “Next steps:” labels to organize notes. Unlabelled text goes into Progress; you can change it in the preview.
